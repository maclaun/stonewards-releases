# StoneWards Official Mod Releases

Official public binary releases repository for **StoneWards Mod Manager**.

This repository contains compiled `.dll` mod binaries used by **StoneWards Mod Manager**. 

## Available Mods
- **StoneWardsHD**: HD graphics, SMAA/TAA anti-aliasing, and anisotropic texture filtering for StoneWards (Unity 6).
